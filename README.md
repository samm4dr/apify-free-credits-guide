# Apify Free Credits Guide

Apify gives every account **free monthly usage credits** — no credit card required. This guide shows how to stretch them into a permanent free scraping setup.

## How CU pricing works

- Compute Units = memory x runtime
- HTTP actors cost ~10x less than browser actors
- Free credits reset every month

## Stay free forever

1. Prefer Cheerio/request-based actors
2. Cap `maxItems` on every test run
3. Batch schedules monthly, not daily
4. Reuse public datasets — zero compute cost

## Get started

[Create a free Apify account](https://console.apify.com/sign-up?fpr=dx06p) — credits apply automatically.
